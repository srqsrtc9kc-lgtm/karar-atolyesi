# Karar Atölyesi

Günlük ürünler için bağımsız ve ücretsiz Türkçe seçim rehberleri.

Bu depo yalnız kamuya açık statik site dosyalarını içerir. Site şu anda mağaza değildir; sipariş, ödeme, üyelik, analitik veya gelir ortaklığı bağlantısı içermez.

## Yerel doğrulama

```powershell
python build_site.py
python build_site.py --check
```

Yayın hedefi: GitHub Pages.
